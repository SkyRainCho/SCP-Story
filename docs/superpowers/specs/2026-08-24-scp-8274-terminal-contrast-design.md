# SCP-8274 日记框对比度设计

## 目标

修复 SCP-8274 私人记事本中浅色日记框使用浅色文字、导致正文难以辨认的问题，同时保持黑色终端和浅色纸张的原有视觉层级。

## 根因

页面的 `.terminal-content` 使用黑色背景，`.terminal-text` 将文字设为白色；其内部 `.blockquote` 在电子书中使用通用浅色引用框背景，却没有同时覆盖继承来的白色文字，因此形成浅底浅字。

## 方案

为 `scp-8274` 添加页面专用 EPUB 样式：

- `.terminal .blockquote` 使用 `#f2f2f2` 浅灰背景。
- 文字使用 `#1a1a1a` 近黑色，确保普通屏幕和灰度墨水屏上均有高对比度。
- 边框使用 `#777` 中灰虚线，保留日记纸框的区隔。
- 不修改终端标题、黑色外框、其他正文引用框或其他页面。

## 验证

- 最小 fixture 证明 SCP-8274 输出页面专用颜色配对。
- 同一结构在其他 slug 中不获得该规则。
- 真实翻译快照中的全部终端日记框仍保留，且样式进入普通 EPUB 与 Kindle Scribe EPUB。
- 运行完整测试并重建 Featured 普通版及 Kindle Scribe 稳定版。
