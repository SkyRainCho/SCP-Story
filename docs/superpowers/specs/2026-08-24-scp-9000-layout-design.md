# SCP-9000 EPUB 排版修复设计

## 目标

让精选集中的 `SCP-9000` 在普通 EPUB 与 Kindle Scribe 稳定版中保持原网页的章节边界：介绍段落中的“毛格群岛”和“SCP-9000 的内部结构”仍按原文左右浮动，而“历史”章节必须在两张图片之后以完整宽度开始；历史卡片内部的 Aquino 肖像和 Site-19 走廊图继续与各自文字并排。

## 根因

原始页面在“历史”章节之前连续使用 `.scp-image-block.block-right` 和 `.scp-image-block.block-left`。网页主题的布局环境会让后续 `.addendumout` 开始在浮动图片之后，但清洗后的 EPUB XHTML 没有在第一个“历史”外框前结束这组页面级浮动。部分阅读器因此让整个历史外框进入两张图片之间的剩余宽度，造成标题竖排、正文成为窄列，并让历史卡片里的图片相互重叠。

## 方案

新增一个仅由配置为 `scp-9000` 启用的页面布局 profile。它只识别直接标题为“历史”的第一个 `.addendumout`，为该节点添加专用 class，并内联 `clear: both` 与 `max-width: 100%`；`box-sizing: border-box` 由该 profile 的样式规则提供，因为通用 XHTML 属性清洗器会按设计移除这一内联属性。不线性化正文图片，也不改变后续 `AQUINO系统` 等同类卡片，避免扩大影响范围。

选择节点时同时校验历史标题和 Aquino 卡片标记，防止页面结构变化后误命中无关外框。现有浮动稳定逻辑仍负责在每个历史内卡片末尾插入清除节点，从而保留原网页的左右图文关系。

## 验证

- 用最小 fixture 复现两个页面级浮动后紧接历史外框的结构。
- 先证明新 profile 测试失败，再实现最小转换规则并使其通过。
- 验证未启用 profile 时输出保持不变，且非“历史”外框不受影响。
- 验证 Featured 配置声明该 profile。
- 运行完整测试，重建普通精选 EPUB 和 Kindle Scribe EPUB/AZW3，并检查构建后的 `scp-9000.xhtml`。
