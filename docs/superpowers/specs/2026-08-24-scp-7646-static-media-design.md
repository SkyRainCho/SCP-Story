# SCP-7646 静态图片与侧栏清理设计

## 目标

将 SCP-7646 中不适用于 EPUB 的三组交互图片转换为唯一的静态图片，并移除页面末尾已经失去实际内容的固定“饮水”侧栏。

## 处理范围

- `PFOA-3D.png`：保留 300px 版本及其说明文字；移除悬停切换、点击全屏层和 600px 重复版本。
- `oat_cn.png`：保留 600px 版本及其说明文字；移除悬停切换、点击全屏层和 300px 重复版本。
- `dupont.png`：保留 600px 版本及其说明文字；移除悬停切换、点击全屏层和 300px 重复版本。
- `.drinkbar`：连同其空白 iframe 外壳、标题和固定定位装饰一起删除。

## 实现方案

新增仅在 `entry.slug == "scp-7646"` 时调用的清洗函数。函数按图片 URL 的文件名识别上述三组媒体，从每组移动端/桌面端副本中选出指定宽度的版本，再将选中版本改造成普通 `scp-image-block`：

- 删除 `image-click-fullscreen`、`image-click-fullscreen-base`、`image-click-fullscreen-image`、`mobile-exit` 等交互结构。
- 去除 `data-feature` 和 `pfoa_mob` / `pfoa_pc` 响应式副本外壳。
- 保留唯一图片与原说明文字，写入明确的静态宽度、自动高度和居中样式。
- 删除同一源图片的另一份重复组件。
- 删除整个 `.drinkbar`。

页面内其他图片和其他 SCP 页面不应用此规则。

## 验证

- 为三个指定图片分别断言只保留一个静态版本，宽度为 300px / 600px / 600px，说明文字不变。
- 断言目标图片不再包含全屏层、切换容器和响应式重复外壳。
- 断言 `.drinkbar` 完全不存在。
- 断言相同输入在非 SCP-7646 页面保持原结构。
