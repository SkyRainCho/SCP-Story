# SCP-4833 EPUB 排版修复设计

## 背景

SCP-4833 的中文原网页在正文档案开始处包含两项特殊布局：

- `.meta-title` 标题使用网页基准字号的 `200%`，在原网页中约为 48px；EPUB 使用较小的基准字号后，实际仅约为 32px。
- O5 警示框使用固定 600px 宽度、若干空段落和远程 `background: url(...)` 水印。转换器为安全起见会移除包含 `url(...)` 的内联样式，EPUB 的段落间距也更紧，导致背景图消失且框体由原网页约 560px 坍缩为约 209px。

SCP-4833 同时存在于 Featured SCP Archive 精选集和 Series 5 的 `4800-4899` 分册（输出为第5卷第9册）。两处构建应使用相同修复。

## 目标

- 恢复 `SCP-4833` 档案标题在 EPUB 中的视觉层级。
- 恢复 O5 警示框的居中水印、接近原网页的纵向比例和文字层级。
- 让警示框在窄屏中不横向溢出。
- 同步应用到精选集和 Series 5。
- 保持普通 EPUB、Kindle 高清版和 Kindle Scribe 稳定版的现有全局行为不变。

## 非目标

- 不全局允许任意内联 CSS 背景 URL。
- 不重构其他使用 `scp_trans.png` 的页面。
- 不追求查看器之间逐像素一致；目标是保留结构、层级和比例。
- 不改变 SCP-4833 的正文、目录标题、图片或折叠内容。

## 配置范围

在以下配置的 `page_overrides.scp-4833` 中启用 `layout_profile: scp-4833`：

- `config/featured-scp.yaml`
- `config/series-5.yaml`

页面 Profile 保持显式配置，不按 slug 全局自动启用。这样可以准确限定影响范围，并沿用 SCP-6183、SCP-4612 和 SCP-6599 的现有模式。

## 转换设计

新增 `scp-4833` 布局 Profile，仅处理满足预期结构的元素。

### 档案标题

Profile 查找可见文本恰为 `SCP-4833` 的 `.meta-title`，添加专用类并覆盖为：

- `font-size: 3em`
- `line-height: 1.2`
- 保留原有底边线、边距和内部段落零边距

如果标题结构不存在，Profile 不创建替代标题，也不修改其他元素。

### O5 警示框

Profile 查找同时包含以下三段文本、且原始内联样式包含 `format-hell/scp_trans.png` 的容器：

- `据O5议会指示`
- `以下文件为5/4833级机密。`
- `未经授权的访问将招致立即处决。`

匹配后执行以下规范化：

1. 删除仅含空白或换行的撑高段落。
2. 将真实警示内容移动到一个专用内部容器中。
3. 外层使用 EPUB 兼容的 table 布局，内部使用 table-cell 垂直居中；不使用 Grid、Flexbox、伪元素或 CSS 生成内容。
4. 外层宽度设为 `100%`、最大宽度为 `600px`、高度约为 `26em`，并保持水平居中。
5. 警示框使用约 `1.25em` 的基础字号；标题与警告文字使用专用相对字号保持层级。
6. 水印使用 `background-size: contain`、居中、不重复，并保持文字在真实 XHTML 中。

## 背景资源本地化

页面 Profile 不直接保留外部 CSS URL，而是在警示框上设置现有的 `data-epub-background-url` 资源标记。转换阶段统一扫描该标记并把 URL 加入页面资源清单，使普通与 Kindle 构建都走现有的下载、缓存、格式识别和本地引用流程。

现有背景资源重写默认强制 `repeat`，用于“关于SCP基金会”等平铺背景。为避免破坏这些页面，新增一个可选的背景重复模式标记：

- 未设置时继续默认为 `repeat`，保持现有行为。
- SCP-4833 显式设置为 `no-repeat`。
- 重写后移除内部数据标记，不把远程 URL 留在最终 XHTML 中。

只接受固定枚举值；无效值回退到 `repeat`。

## 失败处理

- 若页面结构不匹配，Profile 保持无操作，避免错误修改相似正文。
- 若水印下载失败，现有流水线将 URL 写入构建报告的 `missing_assets`；标题、警示文字、尺寸和居中布局仍然保留。
- 若资源成功，最终 EPUB 只引用 `OEBPS/assets/` 下的本地资源。

## 测试策略

### 转换测试

- SCP-4833 Profile 恢复标题专用类和字号。
- 警示框移除空段落、生成垂直居中结构、登记背景 URL 和 `no-repeat`。
- 警示文字仍存在于真实 XHTML。
- 缺少精确文本或背景标识时不修改页面。

### 资源测试

- Profile 标记的背景 URL 进入资源清单并重写为本地路径。
- `no-repeat` 在重写后保留。
- 未提供重复模式的既有背景仍为 `repeat`。
- 无效重复模式安全回退为 `repeat`。

### 配置与流水线测试

- 精选集和 Series 5 都解析到 `layout_profile: scp-4833`。
- 配置驱动的转换任务把 Profile 传给 SCP-4833。

### 成品验证

- 重新构建 Featured 普通 EPUB、Kindle Scribe EPUB/AZW3，以及 Series 5 的 `4800-4899` EPUB。
- 检查 EPUB 压缩结构和资源引用。
- 使用真实浏览器渲染 Featured 普通版与 Scribe 版的 SCP-4833，核对标题字号、警示框高度、水平/垂直居中、背景图和后续分级表布局。

## 验收标准

- `.meta-title` 的计算字号约为 48px（默认 16px 基准字号下为 `3em`）。
- 警示框在宽屏中不超过 600px，在窄屏中不溢出正文宽度。
- 警示框的计算高度接近设计值 `26em`，三段文字垂直居中。
- 水印使用本地 EPUB 资源、完整缩放且不重复。
- 精选集和 Series 5 的 SCP-4833 结果一致。
- 所有新增与既有测试通过；其他页面和非 Kindle 构建行为不变。
