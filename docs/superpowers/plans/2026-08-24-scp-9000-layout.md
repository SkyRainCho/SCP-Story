# SCP-9000 Layout Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent the SCP-9000 history section from flowing beside earlier floated images in Featured EPUB and Kindle Scribe outputs.

**Architecture:** Add an opt-in `scp-9000` layout profile to the existing transform profile registry. The profile will narrowly identify the history addendum, apply a float boundary and safe sizing, and leave the addendum's internal floated images untouched. Featured configuration activates the profile; existing build plumbing passes it to the transformer.

**Tech Stack:** Python 3.11+, BeautifulSoup, YAML, pytest, existing EPUB/Kindle build pipeline.

**Status:** Completed on 2026-08-24; all implementation and verification steps below were executed successfully.
